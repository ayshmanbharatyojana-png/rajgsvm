How availability is calculated

The live Google Sheet facility table is read from columns A:E; the EDL benchmark table is read from columns G:H. The EDL table defines the expected number of drugs for each facility type: DH = 344, CHC = 253, PHC = 211. Each facility is compared with its own type's benchmark. Availability (%) = Active Stock Count ÷ Expected EDL × 100. EDL Gap = Expected EDL − Active Stock Count.
